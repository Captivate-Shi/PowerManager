# 安装包验收

- 首装：默认「为所有用户安装」；通过 Inno 的 Windows shell 目录常量解析 Program Files，不读取硬编码盘符。系统安装仅接收 Program Files 的独立子目录。标准用户可重开 Setup 选择「仅为我安装」，该模式可自定义本地磁盘中的空目录。
- 升级：保留 AppId、安装范围、原路径和数据；原路径只读。全新安装拒绝未登记的非空地址；不迁移或覆盖另一个安装范围的实例。旧 1.6.1 不设例外，继续挡降级。
- 进程：系统安装不以管理员身份启动应用或已安装的脚本。升级或卸载时若余电仍在任一 Windows 会话运行，先从托盘退出；静默运行也不自动启动应用。
- 卸载：遇到额外文件只保留目录，不递归清安装目录。当前用户模式可明确选择清除此用户的余电数据，默认保留，拒绝通过链接清理；系统模式、其他管理员凭据和静默卸载保留个人数据。系统模式卸载前可在应用设置关闭本账户自启。
- 快捷方式：默认创建开始菜单入口；桌面快捷方式可选。右键入口可手动固定到开始，不更改系统布局。

待 Windows 交互验收：普通用户且无 UAC、输入不同管理员凭据、取消 UAC 后重新选择当前用户、中文和英文、旧版定制目录原地覆盖、托盘占用、多用户会话、卸载保留 / 清除、链接/目录哨兵，以及开始菜单入口。Windows CI 的脚本验收与交互实测分别记录。
