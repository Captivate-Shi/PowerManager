# WebView2 性能实测

测量对象是发布前的 WebView2 RC10，环境为一台 Windows 11 x64 电脑，使用模拟外设数据驱动界面。以下是历史基线，不是 0.2.1 的实测结果。

| 场景 | CPU | 私有工作集 |
| --- | ---: | ---: |
| 主窗口打开，停留在总览 | 0.081% | 116 MiB |
| 连续切换页面 | 2.71% | 205 MiB |
| 关闭主窗口，仅托盘和后台监测 | 约 0.003% | 9 MiB |

关闭主窗口后，未观测到余电的 WebView 渲染进程。

| 交互 | 结果 | 口径 |
| --- | ---: | --- |
| 冷启动 | 0.74–1.30 秒 | 完整退出后启动，到主窗口显示；4 次 |
| 托盘快览 | 中位数 414 毫秒 | 注入 Windows 原生托盘单击回调到快览显示，不含手指点击 |
| 切换页面 | P95 23 毫秒 | 35 次切换 |

v0.2.0 的公开 Setup 是 7,318,808 字节（约 7.0 MiB），不包含完整的 WebView2 运行库。
