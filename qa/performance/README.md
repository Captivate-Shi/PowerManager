# PowerManager H5 1.2.0 性能与边界测试

2026 年 11 月 23 日在 Windows 11 x64 上从便携包运行。打开总览、手动刷新、切换页面后关闭主窗口，保留托盘采集。进程连续运行 300 秒，30 个指标样本覆盖 287.5 秒。测试采样间隔为 10 秒，正常使用为 60 秒。

实机识别到 Razer 鼠标、共享接收器键盘及蓝牙 DualSense。Razer 接收器无外设回复，DualSense 处于离线状态。这组指标反映当时的硬件和后台场景。长时间连续在线采样、数小时设备切换和日常负载可用同一份指标检查。

11 项 TypeScript 单元测试涵盖电量边界、精确阈值与区间读数、历史容量和时钟回拨、重复提醒、静音到期、指标缺失和进程更替。C++ 电量协议和历史测试通过。打包版交互回归覆盖托盘单击、连续单击、双击、置顶与取消、设备二级页、非法缩放、取消与确认停止监测。另使用模拟 9% 电量验证自动提醒和去重，连续创建及关闭 16 次测试通知后，通知窗口计数归零。

实机回归验证了采集锁释放后接管、终止采集子进程后自动恢复、关闭主窗口后依然驻留托盘，以及模拟 Electron 休眠和恢复事件后的状态刷新。
