## 1.4.0 外设适配和兼容性报告

- 12 项 TypeScript 测试通过。C++ 报文测试覆盖 VGN 型号白名单、原版与 V3 读数、V3 无线模式切换和零占位、罗技槽位与命令校验、百分比能力、档位区间、充电状态及电压无效值。
- 打包版正常交互、模拟电量提醒和设置里的报告导出均通过。用真实采集进程测试了采集锁占用期间的只读报告、采集可用后的报告和进程恢复。报告不带 HID 路径、设备实例 ID、序列号、设备实体 ID 或原始输入报告。
- 本机只读枚举识别到 18 个 HID 接口，包括已有 Razer 和 DualSense 路径。当次没有连接待测 VGN V98 Pro 或 Logitech 接收器。新增协议结论以报文测试和上游型号记录为依据。

## 1.3.0 提醒优先级与设备发现

- 打包界面验证了点击 20% 的上箭头得到 21%、按键步进、1% 和 95% 边界、非法 0%、单设备覆盖、恢复全局值、错误校验后的恢复和单设备静音。
- 页面用两个不同电量的设备验证全局紧急线优先。模拟采集以普通低电量设备在前的顺序返回结果，实际通知仍先出紧急提醒，再出普通提醒。
- TypeScript 检查和 12 项单元测试通过。C++ 电量协议、设备总线分类和历史测试通过。本机 Windows 发现测试发现 1 个 USB、1 个蓝牙容器，两者均无可用的 Windows 电量属性。当前会话的 1.2.0 仍占用实机采集锁。
- 清理根目录后从 H5 单独构建并通过便携版回归。[设备阈值截图](14-device-threshold.png) · [兼容性与集成评估](../COMPATIBILITY.md)

## 1.1.0 界面验收

| 检查 | 结果 |
| --- | --- |
| 显示大小 | 主窗口与托盘分别从 100% 调至 125%，两者缩放互不影响。验证了 1280×720 布局、150% 系统缩放及键盘焦点。 |
| 托盘 | 向打包版的 Electron Tray 注入单击、重复单击和双击，确认单击打开、重复单击保持浮窗、双击打开主窗口。置顶窗口支持移动、改变尺寸，并可跳转设备详情。 |
| 设备流程 | 验证搜索、网格与列表切换、双击打开二级页、Esc 返回、蓝牙读取入口和确认对话框。 |
| 桌面提醒 | 验证普通与紧急预览、弹窗关闭与焦点保留。另以独立采集测试程序注入 9% 读数，验证自动弹窗和本次低电量去重。 |
| 自动检查 | TypeScript 类型检查、6 项采集与提醒测试、C++ 电量与历史测试、打包版交互回归均通过。 |
