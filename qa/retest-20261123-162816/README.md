通用“预览低电量”通知正文点击后只关闭通知，仍停留在提醒页。设备详情的“提醒测试”正文点击后进入对应设备详情并关闭通知。通用预览使用虚拟设备，这是两类入口的实际行为差异，是否需要给通用预览提供跳转目标取决于产品预期。

“全屏提示音”开关在极快的连续输入中出现过一次反向操作未生效。测试在首次点击已更新主进程数据、界面仍显示旧值时立即按空格。等待开关视觉状态更新后，三个提醒开关均可用鼠标和键盘往返。复测证据不足以推断正常手速下的发生率。
